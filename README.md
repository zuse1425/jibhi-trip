# 🏔️ Jibhi Trip App

One link for our 13–16 Nov trip: the plan with live **Now / Next**, 📍 Google Maps links for every place, an **Ideas** board (suggest → vote → decide), and group **Chat**. Everything syncs live between our phones and works offline.

**Open:** https://zuse1425.github.io/jibhi-trip/ → Chrome ⋮ → *Add to Home screen*.
First open: pick your name + enter the trip passcode (ask Naman).

### For devs
Static HTML/CSS/JS + Supabase. See `CLAUDE.md`, `docs/trip-context.md` and `specs/001-trip-companion-app/`.
Local preview: `python3 -m http.server` → http://localhost:8000
